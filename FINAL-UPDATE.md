# Nadeem Mobiles v3.0

This is a functional cleanup package. It includes a complete GitHub Pages `docs/` folder and the Cloudflare Worker API.

Production roles:
- GitHub Pages `docs/` = dashboard
- Cloudflare Worker `cloudflare-worker/` = API
- D1 `nadeem-mobiles-db` = database
- Firebase FCM = phone commands
- `android-app/` = Android client

Do not upload Firebase service-account JSON or `.env` secrets to GitHub.
